Scoped Drive

Scoped Drive is a gateway that sits in front of Google Drive.

You sign in with Google, then tick the files and folders an assistant may use. Drive’s API cannot limit an app to those items, so this server checks every call against your list before it reaches Drive. Anything you have not allowed is refused. If the assistant asks for something else, you get a link to allow or deny it.

Only the Google account configured as the owner can sign in. The assistant reaches Drive only through a connection that owner created, and only for the items that owner allowed.
