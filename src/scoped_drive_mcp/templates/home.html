Scoped Drive

Scoped Drive is a gateway that sits in front of Google Drive.

Drive’s API does not give an app a fine-grained way to share only certain files and folders. An app that signs in receives a broad Drive permission. This server is the missing control: you tick the files and folders an assistant may use, and every call is checked against that list before it reaches Drive.

Only the Google account configured as the owner can sign in. An assistant reaches Drive only through a connection that owner created, and only for the items that owner allowed.
